# Темний інтерфейс RehaFlow

Оновлено наявний React-інтерфейс усередині WinUI 3 / WebView2. API, права доступу,
обробники клінічних операцій і нативна оболонка не змінені.

## Ефекти

Перемикач доступний на екрані входу та у верхній панелі після входу.

- **Авто**: вимикає анімації, якщо браузер повідомляє не більше 4 логічних
  процесорів або не більше 4 ГБ пам’яті. Це приблизна оцінка, не вимірювання FPS.
- **Увімкнено**: два повільні градієнтні шари, короткі переходи кнопок,
  поява заголовків, діалогів та повідомлень.
- **Еко**: без анімацій і декоративних фонових шарів, темна тема залишається.

Системне налаштування зменшення руху має пріоритет навіть над «Увімкнено».
Анімації призупиняються при втраті фокуса або приховуванні сторінки.
Режим зберігається для цього пристрою й адреси сервера в localStorage.
Недоступність localStorage не блокує перемикання в поточному сеансі.

Немає нових production-залежностей, WebGL, canvas, відео, таймерів кадрів,
анімації blur/backdrop-filter чи геометрії макета. Відсутність лагів на довільному
ПК не гарантується: на цільовому обладнанні перевірте «Авто» та «Еко» з робочими
обсягами даних. Витрати існуючих API-запитів і таблиць залишаються окремим фактором.

## Оновлення

React завантажується оболонкою з локального сервера. Оновіть сервер до цієї гілки,
встановіть залежності за чинною інструкцією та виконайте `npm run build`.
Перезапустіть сервер і натисніть «Оновити» у десктопному клієнті.
Лише заміна EXE без оновлення серверного web/dist не змінить тему.

## Перевірки

1. `npm ci` та `npm run build -w web`.
2. Для браузерної перевірки встановіть Playwright поза production-залежностями
   проєкту і його Chromium (`playwright install chromium`).
3. Запустіть `node scripts/desktop-preview.mjs` з кореня репозиторію.
4. Запустіть `node scripts/check-appearance.mjs`. За потреби задайте
   `PLAYWRIGHT_MODULE` як абсолютний шлях до `playwright/index.mjs`.
   `APPEARANCE_SCREENSHOT` задає шлях знімка; за замовчуванням `/tmp/quremed-appearance.png`.

Перевірка використовує фіктивні API-відповіді тільки у браузері тесту та не
підключається до бази клініки. Перевіряє вхід, режими ефектів, збереження вибору,
зменшення руху, паузу, діалог пацієнта, мобільну навігацію і авто на двох ядрах.
Запуск Windows EXE перевіряється окремим наявним GitHub Actions workflow.
