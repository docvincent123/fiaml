# RehaFlow 3.0 — завдання за зміну

Оновити APK і сервер разом. Android versionCode 11.

- Нативні завдання запитують scope=shift: незавершені до кінця зміни (також прострочені), власні у роботі та виконані протягом зміни. Для адміністратора без зміни — поточний серверний день.
- Загальний архів пацієнтів і призначень доступний лише адміністратору. У нативному клієнті архів прибрано.
- Пошук призначень за пацієнтом, номером, палатою чи ліжком; показ місця у картках. Нативний вибір вільного ліжка під час реєстрації. Сервер повторно перевіряє зайнятість.
- Новий канал сповіщень використовує наданий рингтон. Нове завдання у фоні повторює звук; повернення у NativeActivity скасовує сповіщення та звук. Перша синхронізація нового облікового запису фіксує поточні події без дзвінка.

## Перевірка на телефоні
1. Увійти, почати й підтвердити зміну; дозволити сповіщення.
2. Згорнути додаток, створити завдання іншому працівнику з відповідною роллю. Перевірити повторення мелодії та відкриття завдань зі сповіщення.
3. Повторити зі заблокованим екраном; відкрити через іконку — звук має зупинитися. Оновлення не повинно повторно дзвонити за стару подію.
4. Завершити завдання — воно лишається серед виконаних цієї зміни. Майбутні дні курсу не показуються; прострочені лишаються.
5. Перевірити нативні переходи палата → ліжко → пацієнт → призначення і реєстрацію з вибором вільного ліжка.

Фонова доставка залежить від доступу до локального сервера, дозволів і системних обмежень Android. Чинний dataSync-сервіс має часові обмеження Android 15; безперервну доставку протягом усієї довгої зміни не гарантовано. Примусове зупинення застосунку припиняє доставку. Беззвучний режим і «Не турбувати» не обходяться. Фізична перевірка звуку та екранів ще потрібна.
